# Photo café demo

The default room is an estimated reconstruction of the supplied `IMG_8179.HEIC` photograph. It is a 6.4 × 9.6 × 3.4 m café lounge; these dimensions and object positions are visual estimates, not LiDAR measurements. The UI labels it **Photo demo · estimated dimensions**. The original photograph is not bundled or uploaded.

The layout follows the visible photo: a left-wall upholstered banquette, small tables and office chairs, three joined white café tables, a dark rear counter with red/white/red bar stools, and right-wall display shelving with books, plants and chess pieces. The aisle from the entrance to the rear door stays open. People in the photograph are omitted; Play uses the existing casual avatar.

The 53 scene objects use 24 distinct GLBs. Twelve are reused from the existing library: `sofa_3seat`, `chair_office`, `shelf_open`, `bookshelf`, `cabinet_simple`, `plant_indoor_tall`, `plant_potted_medium`, `plant_potted_small`, `pot_empty`, `trash_bin`, `laptop`, and `monitor_desktop`.

Twelve original props fill gaps in the library: `table_cafe`, `chair_cafe`, `stool_bar`, `counter_cafe`, `coffee_machine`, `chess_king`, `chess_pawn`, `books_stack`, `pendant_cafe`, `mountain_art`, `track_ceiling`, and `floor_oak_cafe`. These use embedded geometry and PBR colors, with no external textures or decoder dependencies. The chess models are turned profiles with a cross on the king and a spherical pawn head. Shelf ornaments are approximate interpretations of the photo, with chess pieces added as requested.

Edit the layout in `backend/app/cafe_scene.json`. Object positions are bounding-box centres, sizes are width × height × depth, and rotation is in radians. The source is included in the backend package and Vercel function bundle. Reconstruction restores each model's identity after the initial unlabeled demo sweep.

Rebuild only the new models and their manifest entries with:

```sh
python3 models/source/build_cafe.py
```

This preserves the existing library and Blender file. The new models are generated by the Python source and are not part of the original `.blend` gallery. Model dimensions and triangle counts are recorded in `models/manifest.json`; the older validation reports describe the original 30 assets. `src/scene/catalogModel.test.ts` loads all current catalog GLBs through the application's Three.js loader and verifies dimensions and material isolation.
